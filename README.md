# Шаблон отчёта МТУСИ в Typst

- [template/](template) — самостоятельный шаблон для новой лабораторной.
- [work/](work) — техническое описание, собранное на этом шаблоне. В [work/examples/](work/examples) находятся исходный LaTeX-образец и его перенос в Typst.

## Новая лабораторная

Скопируйте каталог `template/` целиком. Заполните `report.toml`, напишите введение, цель и заключение в `sections/`. Главы хранятся в `sections/chapters/`, а их порядок задаёт `sections/chapters.toml`.

Из скопированного каталога выполните:

```sh
typst compile report.typ
```

Автор использует обычные заголовки Typst. Правила нумерации, содержания, подписей и титульника находятся в `styles/`.

## Список источников

Заполняйте `references/library.yml` в формате Hayagriva и ссылайтесь на ключи из глав через `@ключ`. Для импорта статей и патентов из JSON укажите путь к файлу в `[bibliography].file` файла `report.toml`.

Язык источника задаётся в `language` для YAML и в `lang` для JSON. Например, `en-GB` включает английские правила переноса для этой записи. Шаблон использует числовые ссылки по ГОСТ Р 7.0.5–2008 и сокращения для русского, английского, немецкого и французского языков. Если язык опущен, используется русский. Для остальных языков используются переносы Typst при наличии словаря и английские сокращения.

Для сайта укажите URL и, если известна, дату обращения в `url.date` в формате `ГГГГ-ММ-ДД`. Для справки задайте `bibliographic-note = true` и укажите группы в `references/publications.yml`.

## Сборка технического описания и примера

Из корня репозитория выполните:

```sh
typst compile --root . work/report.typ
typst compile --root . work/examples/postgresql/report.typ
```

Команды создают `report.pdf` рядом с соответствующим `report.typ`. Сборка проверена на Typst 0.14.2.

# Шаблон отчёта МТУСИ в Typst

[Репозиторий проекта на GitHub](https://github.com/kakoito-off/typst-mtuci-template)

- [template/](template) — самостоятельный шаблон для новой лабораторной.
- [work/](work) — техническое описание, собранное на этом шаблоне. В [work/examples/](work/examples) находятся исходный LaTeX-образец и его перенос в Typst.

## Новая лабораторная

Скопируйте каталог `template/` целиком. Заполните `report.toml`, напишите введение, цель и заключение в `sections/`. Главы хранятся в `sections/chapters/`, а их порядок задаёт `sections/chapters.toml`.

Из скопированного каталога выполните:

```sh
typst compile report.typ
```

Автор использует обычные заголовки Typst. Правила нумерации, содержания, подписей и титульника находятся в `styles/`.

В `report.toml` задайте одинарный (`1`) или полуторный (`1.5`) межстрочный интервал.

```toml
[layout]
line-spacing = 1.5
```

Для разовой сборки можно передать `--input line-spacing=1.5` в команде `typst compile`.

## Названия глав в содержании

В начале файла главы можно задать отдельное название для содержания.

```typst
#let toc-title = "Результаты"

= Анализ результатов эксперимента
```

Параметр относится к первому заголовку уровня `=` в файле. Если `toc-title` пустой или отсутствует, в содержание попадает обычный заголовок главы.

## Список источников

Заполняйте `references/library.yml` в формате Hayagriva и ссылайтесь на ключи из глав через `@ключ`. Для импорта статей и патентов из JSON укажите путь к файлу в `[bibliography].file` файла `report.toml`.

Язык источника задаётся в `language` для YAML и в `lang` для JSON. Например, `en-GB` включает английские правила переноса для этой записи. Шаблон использует числовые затекстовые отсылки по ГОСТ Р 7.0.5–2008 и сокращения для русского, английского, немецкого и французского языков. Если язык опущен, используется русский. Для остальных языков используются переносы Typst при наличии словаря и английские сокращения.

Для сетевого документа укажите точный URL в `url.value` и фактическую дату обращения в `url.date` в формате `ГГГГ-ММ-ДД`. Для специальных источников, например стандартов и патентов, состав реквизитов зависит от вида документа. [ГОСТ Р 7.0.108–2022, разделы 5 и 6](https://library.csu.ru/media/files/i-culture/7_0_108-2022.pdf)

Если нужна библиографическая справка, напишите и оформите её в `sections/bibliographic-note.typ`. Шаблон вставит содержимое файла после списка источников.

## Сверка с ГОСТ 7.32–2017

Шаблон следует образцу МТУСИ для лабораторных работ. ГОСТ 7.32–2017 задаёт оформление отчётов о НИР. [ГОСТ 7.32–2017](https://library.istu.edu/content/gost-7-32-2017.pdf)

| Требование | Шаблон МТУСИ | ГОСТ 7.32–2017 |
| --- | --- | --- |
| Формат, основной шрифт, красная строка | А4, Times New Roman 14 пт при наличии, 12,5 мм | А4, не менее 12 пт, рекомендован Times New Roman, 12,5 мм (п. 6.1.1) |
| Поля по краям | Слева 25 мм, справа 10 мм, сверху и снизу по 20 мм | Слева 30 мм, справа 15 мм, сверху и снизу по 20 мм (п. 6.1.1) |
| Межстрочный интервал | 1 или 1,5 | 1,5. Для заключительного отчёта от 500 страниц допускается одинарный (п. 6.1.1) |
| Нумерация страниц | Сквозная, внизу по центру области набора. Титульный лист учитывается, его номер скрыт | Сквозная, в центре нижней части страницы. Титульный лист учитывается, его номер скрыт (пп. 6.3.1–6.3.2) |
| Структура | Титульный лист лабораторной, «Цель работы» и главы. Главы могут идти подряд | Свой состав структурных элементов и реквизитов титула. Структурные элементы и разделы начинают с новой страницы (раздел 4, пп. 6.2.1, 6.10.1) |
| Содержание | Отточия, номера страниц справа, заголовки первого уровня, опциональные названия глав в содержании | Отточия и номера страниц справа. Перечисляют наименования разделов, подразделов и озаглавленных пунктов (пп. 5.4.1, 6.13) |
| Подписи | «Рис.», «Табл.», на продолжении таблицы повторяется её название | «Рисунок», «Таблица» и «Продолжение таблицы» с номером. Подпись таблицы слева без красной строки (пп. 6.5.7, 6.6.3) |
| Затекстовые отсылки | Номера в квадратных скобках, список в порядке первого цитирования с номерами и красной строкой | Те же правила нумерации и расположения записей (пп. 6.9.1, 6.16) |

## Сборка технического описания и примера

Из корня репозитория выполните:

```sh
typst compile --root . work/report.typ
typst compile --root . work/examples/postgresql/report.typ
```

Команды создают `report.pdf` рядом с соответствующим `report.typ`. Сборка проверена на Typst 0.14.2.
